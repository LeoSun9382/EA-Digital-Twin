## 📋 简介与核心理念
本系统是一个专门为高级助理（EA）场景量身打造的**「人格滤镜驱动 (Persona-Driven)」AI 引擎**。

它摒弃了死板的通用公文模板。通过内置的自动化采集向导，它能一次性萃取出你所服务高管的性格、格式偏好与业务红线。在此后的每一次对话中，系统都会自动套用这位老板的“脾气形态”，为您完成跨部门博弈、资源协调与文案撰写。

> 🛡️ **最高安全脱敏原则**：
> 本系统的卓越表现在于“工作逻辑的精准模拟”，完全不依赖您公司的真实机密。**请在一切对答中：全程使用化名（如：技术部王总）、模糊金额、泛指行业。绝不可喂给 AI 真实的商业报表数据。**

## 🚀 安装与初次使用

### 1. 初装极简启动（免口令识别）
你不需要死记硬背任何命令指令！
由于采用了 L0 级强制侦测，只要将本项目安装并打卡聊天框，**随意对 AI 说一句话（比如“你好”）**，系统便会察觉您还未建档，从而自动中断对话，引导您进入约需 5 分钟的 **Onboarding 会话流程**。

### 2. 日常配置与进化命令
- `/add-boss`：【兼管神器】当您还需要支持其他的高管时，呼出此指令，建立一套完全独立的人格库。日后只需在指令里带出代称（如“帮王总做...帮李总做...”），系统便会自动无缝切换。
- `/config`：手动进入“配置中心”，大规模修缮某位老板的红线库。
- **🤫 隐性进化反馈 (重要)**：当发现 AI 产出不准时，只需在对话框随口抱怨（如“张总现在已经不喝茅台了，记住这事”）。系统会自动将您的规训写入 `Feedback_Log.json`，永久学习。

## 🔧 运行环境与配置需求

本框架深度依赖大语言模型的“利益博弈常识”与“微操语义理解”，必须配合一流配置方可达到实战效果。

### 1. 推荐的驱动大模型 (LLMs)
- **第一梯队 (旗舰闭源)**：优先推荐采用基于平台的 **Antigravity** 环境。强烈推荐搭载 **Gemini 3 / Gemini 3.1 Pro (High)** 环境，或采用 **Claude 3.5 Sonnet / 4.6 Opus**。这四大模型能最精准地把握体制内与商场上的言下之意。
- **特化适用 (国内顶流)**：针对极具中国本土特色的国企/政企官样文章及人际边界，可搭配使用国内大语言模型进行单点生成验证（推荐：DeepSeek V3 / R1，或智谱 GLM-4 等具有高阶长文本处理能力的模型）。

### 2. 外部 MCP 工具配置 (重要强化)
为了能彻底盘活部分功能，建议使用者在平台环境中配置以下 MCP (Model Context Protocol) 插件：
- **`notebooklm-mcp`**：在处理 **[行业简报]** 与 **[VIP情报]** 时，当你拥有超长研报或上百页履历文件，借助此 MCP 让 AI 抓取海量文献，可保障输出内容的零幻觉与高精度。
- **图像生成 MCP (如 `nanobanana` 等)**：在使用 **[图文可视化 Viz_Enhancer]** 时，配置此生图工具，可让指令真正落到实处，一键生成商务风格的配图素材。

## 📁 核心项目结构指引

所有的个性化配置均留存在您的本地文件中，确保不会发生跨端参数泄露：

```
EA-Digital-Twin/
├── SKILL.md                  # 👉 核心大脑（含分发路由与引擎启动入口）
├── README.md                 # 您正在阅读的手册
├── Prompts/                  # 14 个核心功能的业务推演逻辑
├── References/               # 运行时参考数据库
│   ├── Bosses/               # [自动生成] 各高管人格衍生字段 (Boss_xxx.md)
│   ├── Constraints.md        # [自动生成] 高压合规红线库 (核心拦截器)
│   ├── User_Profile.md       # [自动生成] 助理自身的长短板与身份配置
│   ├── Feedback_Log.json     # [动态进化] AI自动捕捉您吐槽学习的日常备忘
│   ├── Project_Log.json      # [任务追踪] 记录项目进度与逾期预警
│   ├── Expense_Log.json      # [费用管理] 记录日常经费支出与预算对撞
│   └── (其他运行时配置)
└── .agent/
    ├── instructions.md       # L0 强制安全规则与执行拦截网
    └── workflows/            # 配置指令自动化引导脚本 (init/add-boss/config)
```
