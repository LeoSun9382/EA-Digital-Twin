## 📋 简介与核心理念
本系统是一个专门为高级助理（EA）场景量身打造的**「人格滤镜驱动 (Persona-Driven)」AI 引擎**。

它摒弃了死板的通用公文模板。通过内置的自动化采集向导，它能一次性萃取出你所服务高管的性格、格式偏好与业务红线。在此后的每一次对话中，系统都会自动套用这位老板的“脾气形态”，为您完成跨部门博弈、资源协调与文案撰写。

> 🛡️ **最高安全脱敏原则**：
> 本系统的卓越表现在于“工作逻辑的精准模拟”，完全不依赖您公司的真实机密。**请在一切对答中：全程使用化名（如：技术部王总）、模糊金额、泛指行业。绝不可喂给 AI 真实的商业报表数据。**

## 🚀 安装与初次使用

### 1. 初装极简启动（免口令识别）
你不需要死记硬背任何命令指令！
由于采用了 L0 级强制侦测，只要将本项目安装并打卡聊天框，**随意对 AI 说一句话（比如“你好”）**，系统便会察觉您还未建档，从而自动中断对话，引导您进入约需 5 分钟的 **Onboarding 会话流程**。

### 2. 日常配置与进化命令
- `/add-boss`：【兼管神器】当您还需要支持其他的高管时，呼出此指令，建立一套完全独立的人格库。日后只需在指令里带出代称（如"帮王总做...帮李总做..."），系统便会自动无缝切换。
- `/config`：手动进入"配置中心"，大规模修缮某位老板的红线库。
- **🤫 隐性进化反馈 (重要)**：当发现 AI 产出不准时，只需在对话框随口抱怨（如"张总现在已经不喝茅台了，记住这事"）。系统会自动将您的规训写入 `Feedback_Log.json`，永久学习。若新规则与旧规则矛盾，系统会自动以最新为准。
- **💾 情境模板**：当你满意某次输出的格式时，说"存为模板"即可保存。下次同类任务只需说"按 [模板名] 出一份"，零输入直接产出。

## 🔧 运行环境与配置需求

本框架深度依赖大语言模型的“利益博弈常识”与“微操语义理解”，必须配合一流配置方可达到实战效果。

### 1. 推荐的驱动大模型 (LLMs)
- **第一梯队 (旗舰闭源)**：强烈推荐搭载 **Gemini 3 / Gemini 3.1 Pro (High)** 或 **Claude 3.5 Sonnet / 4.6 Opus**。这四大模型能最精准地把握体制内与商场上的言下之意。
- **特化适用 (国内顶流)**：针对极具中国本土特色的国企/政企官样文章及人际边界，可搭配使用国内大语言模型进行单点生成验证（推荐：DeepSeek V3 / R1，或智谱 GLM-4 等具有高阶长文本处理能力的模型）。

### 2. 兼容的 Agent 平台
本 Skill 采用**能力槽位 (Capability Slots)** 架构，不绑定任何特定平台。以下环境均可运行：
- **Antigravity**：`.agent/instructions.md` 自动注入，开箱即用。
- **OpenClaw 及类似 Skill 编排平台**：平台读取 SKILL.md 后自动匹配已安装的其他 Skill/工具。
- **Cursor / Windsurf / Claude Code**：将 SKILL.md 首行的 `Auto_Load_Rule` 内容复制到对应平台的配置文件中（如 `.cursorrules`、`CLAUDE.md`）。
- **其他 Agent 工具**：手动告知 AI "读取 SKILL.md 并按照它执行" 即可。

### 3. 外部能力增强（可选，非必需）
本系统的 14 大核心模块**无需任何外部工具即可完整运行**。以下工具可进一步增强特定场景：

| 能力槽位 | 推荐工具 | 增强效果 |
|:---|:---|:---|
| 🔍 深度文档研究 | `notebooklm-mcp`、`perplexity` 等 | 超长研报/PDF 零幻觉深度提取 |
| 🌐 联网搜索 | `tavily-search` 等 | 实时行业动态/VIP 最新情报 |
| 🎨 图像生成 | 平台内置生图工具 | 一键生成商务风格信息图 |
| 🌏 多语言翻译 | 专业翻译 MCP/Skill | 涉外致辞/接待材料高精度翻译 |

## 📁 核心项目结构指引

所有的个性化配置均留存在您的本地文件中，确保不会发生跨端参数泄露：

```
EA-Digital-Twin/
├── SKILL.md                  # 👉 核心大脑（含分发路由与引擎启动入口）
├── README.md                 # 您正在阅读的手册
├── Prompts/                  # 14 个核心功能的业务推演逻辑
├── References/               # 运行时参考数据库
│   ├── Bosses/               # [自动生成] 各高管人格衍生字段 (Boss_xxx.md)
│   ├── Constraints.md        # [自动生成] 高压合规红线库 (核心拦截器)
│   ├── User_Profile.md       # [自动生成] 助理自身的长短板与身份配置
│   ├── Feedback_Log.json     # [动态进化] AI自动捕捉您吐槽学习的日常备忘
│   ├── Project_Log.json      # [任务追踪] 记录项目进度与逾期预警
│   ├── Expense_Log.json      # [费用管理] 记录日常经费支出与预算对撞
│   ├── Templates/             # [情境模板] 用户保存的常用输出格式模板
│   └── (其他运行时配置)
└── .agent/
    ├── instructions.md       # 轻量引导器（仅指向 SKILL.md）
    └── workflows/            # 配置指令自动化引导脚本 (init/add-boss/config)
```
