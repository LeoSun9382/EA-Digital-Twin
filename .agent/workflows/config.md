# ⚙️ 配置中心 (Config / Edit)

**触发时机**：用户输入 `/config` 时触发。

## 🎯 核心执行指令
开启修改配置意图时，展示当前的模块架构供选择。

### 询问修改诉求
**[你要发给用户的参考]**：
> "配置中心已唤醒。您希望手工修缮哪一模块的数据？
>
> 1. **修改通用或是某个老板的高压红线库**
> 2. **微调修改老板性格偏好**
> 3. **改变自身（助理）服务他的定位**
>
> 请直接告诉我您的新增要求或想要废弃的规则。"

### 处理流程
1. 读取涉及的对应文件：如果改红线则操作 `Constraints.md`，性格则操作 `Bosses/` 目录里的文件。
2. 修改文件里的信息，或是通过重演 AI 衍生字段替代旧的规则。
3. 给用户的温情提示机制：
> "✅ 规则已更新。\n📢 给您一个小提示：其实对于极个别的风格微调小忌讳，您不需要特意进 config 调整。日常聊天时您随便说一句类似于（XX总不看带柱状图的报告了），我就会自动写进 Feedback 档案去吃透。"
